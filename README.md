# zonehttp

Zone identifiers and http tokens for idempotent workflows.

**Site:** https://theworker02.github.io/zonehttp/

## Install / run

```bash
git clone https://github.com/theworker02/zonehttp.git
cd zonehttp
node src/cli.js
node --test
```
